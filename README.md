# Java & Spring Boot Developer Roadmap 🚀

This repository documents hands-on coding exercises, projects, and notes based on the **Telusko (Navin Reddy) Complete Java & Spring Boot Developer Course**.

---

## 📌 Repository Overview

This repository tracks the transition from foundational Core Java principles to enterprise-grade backend systems using Spring Boot and microservices architecture.

### Current Project Structure

```text
Java_Springboot_telusko/
│
├── Core_Java/                   # Core Java basics, OOPs, Collections, and Streams
│   ├── 01_Basics_Operators/     # Variables, Data Types, and Operators
│   ├── 02_Control_Flow/         # Conditionals, Loops, and Jump Statements
│   ├── 03_OOPs/                 # Classes, Objects, Inheritance, Polymorphism
│   ├── 04_Exception_Handling/   # Custom Exceptions, Try-Catch-Finally
│   ├── 05_Collections_Streams/  # List, Set, Map, and Stream API
│   └── ...
│
├── Database_JDBC/               # SQL queries, JDBC connectivity, and DAO patterns
├── Spring_Core/                 # Inversion of Control (IoC), Dependency Injection (DI)
├── Spring_Boot_REST_APIs/       # Controllers, Services, Repositories, DTOs, Swagger
├── Spring_Security/             # Authentication, Authorization, JWT, OAuth2
└── Microservices/               # Service registry, API Gateway, inter-service comms
